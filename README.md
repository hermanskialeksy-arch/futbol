# Typy piłkarskie

Strona odświeża się sama co 3 godziny (zakładka Actions → Run workflow = odśwież teraz).

## Braki kadrowe (braki.json)

Pola wpisu: `gracz`, `rola` (atak/pomoc/obrona/bramkarz/?), `waga` (1.0 pewny brak, 0.3–0.8 wątpliwy), `powod`, `do`, opcjonalnie `klucz: true` (gwiazda – wpływ liczony podwójnie). Braki zmieniają oczekiwane gole, strzały, celne i rożne w meczu.
